# Example: UI instructions

## Original

To continue to the next step in the onboarding process, click the Continue button below.

## Light

Click Continue to go to the next onboarding step.

## Balanced

Continue onboarding

## Strong

Continue

## Notes

- Instructions that explain obvious UI mechanics can usually become labels.
- Use the stronger versions only when the UI context makes the action clear.

## Original

Please type DELETE in the field below to confirm that you want to permanently delete this workspace.

## Light

Type DELETE to confirm that you want to permanently delete this workspace.

## Balanced

Type DELETE to permanently delete this workspace.

## Strong

Type DELETE to delete this workspace permanently.

## Notes

- Preserves the confirmation requirement.
- Preserves permanence.
- Does not reduce the destructive-action warning to only “Delete”.
