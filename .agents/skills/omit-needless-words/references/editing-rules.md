# Editing rules

## Remove or rewrite

Remove or rewrite:

- happy talk: welcome text, self-praise, friendly but empty introductions;
- meta text: “this page explains”, “in this section”, “below you will find”;
- filler: “please note”, “in order to”, “it is important to”, “simply”, “just”;
- obvious instructions: “click the button below”, “enter your name in the name field”;
- repeated meaning across headings, paragraphs, links, or calls to action;
- vague claims: “easy”, “powerful”, “seamless”, “robust”, unless specific and useful;
- internal perspective: “we are pleased to announce”, “our team has worked hard”;
- reassurance before the user has a reason to doubt;
- throat-clearing before the real point;
- long transitions that do not guide action.

## Prefer

Prefer:

- direct labels over explanatory sentences;
- specific nouns and verbs over generic claims;
- short paragraphs over dense blocks;
- front-loaded sentences;
- action-oriented headings;
- concrete next steps;
- the shortest wording that preserves meaning;
- structure over instruction.

## Sentence-level moves

Use these transformations:

| Before                                    | After              |
| ----------------------------------------- | ------------------ |
| in order to                               | to                 |
| due to the fact that                      | because            |
| at this point in time                     | now                |
| it is important to remember that          | remember           |
| please be aware that                      | note / remove      |
| you have the ability to                   | you can            |
| make sure that you                        | make sure / verify |
| there are several different ways in which | several ways       |
| the process of setting up                 | setup / setting up |
| successfully complete                     | complete           |

## Structure-level moves

Use these transformations:

- Turn paragraphs of instructions into numbered steps.
- Turn repeated explanatory text into one heading.
- Replace “welcome” sections with the user’s first useful action.
- Move warnings before the risky step.
- Move prerequisites before instructions.
- Move decision criteria before options.
- Remove duplicate context after headings.
