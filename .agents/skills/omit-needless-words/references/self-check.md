# Self-check

Before finalizing, compare the revised version against the original.

## Task clarity

- Is the reader's task clearer?
- Is the main action easier to find?
- Are headings more useful?
- Is the copy easier to scan?

## Compression quality

- Is happy talk removed?
- Is meta text removed?
- Are instructions reduced, not merely rephrased?
- Are repeated meanings merged?
- Are vague claims replaced with useful specifics?

## Preservation

- Is required detail preserved?
- Are warnings preserved?
- Are prerequisites preserved?
- Are exceptions preserved?
- Are commands, paths, API names, and configuration values unchanged?
- Are decision-critical distinctions preserved?

## Risk

- Did the edit make the text cryptic?
- Did the edit remove useful warmth from sensitive copy?
- Did the edit turn documentation into a summary?
- Did the edit remove examples that prevent mistakes?
- Did shorter wording reduce accuracy?

If any answer reveals a problem, revise before returning the output.
